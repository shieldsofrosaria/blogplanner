# 🌟 SL Blog Planner

A simple web application for planning Second Life blog posts and managing credits. Easily organize your blog posts and export formatted credits for designers, photographers, and creators.

## ✨ Features

- **Blog Post Management**: Create, edit, and organize your blog posts with titles, dates, and notes
- **Credits Management**: Add and categorize credits for:
  - Designers
  - Photographers
  - Hair, Skin, Eyes
  - Clothes & Accessories
  - Poses
  - Locations
  - And more!
- **Export Options**: 
  - Export as plain text
  - Export as HTML (ready for blog posting)
  - Copy to clipboard with one click
- **Local Storage**: All data is saved in your browser - no server needed
- **Responsive Design**: Works on desktop, tablet, and mobile

## 🚀 Getting Started

### Usage

1. Open `index.html` in your web browser
2. Click "**+ New Post**" to create a blog post
3. Fill in the post title, date, and any notes
4. Click on a post to select it and start adding credits
5. Add credits by selecting the type, entering brand/creator, item name, and optional URL
6. Export your credits in text or HTML format
7. Copy to clipboard and paste into your blog!

### No Installation Required

This is a standalone web application that runs entirely in your browser. Simply open `index.html` to get started. No server, build process, or dependencies needed!

## 📖 How to Use

### Creating a Blog Post

1. Click the "**+ New Post**" button
2. Enter your post title (e.g., "Summer Beach Look")
3. Select the date
4. Add any notes or ideas for the post
5. Click "**Save Post**"

### Adding Credits

1. Click on a blog post to select it
2. Choose the credit type from the dropdown (Designer, Hair, Skin, etc.)
3. Enter the brand or creator name
4. Enter the item name
5. Optionally add a URL link
6. Click "**Add Credit**"
7. Repeat for all credits

### Exporting Credits

1. Select a post with credits
2. Click "**Export as Text**" for plain text format
3. Click "**Export as HTML**" for HTML formatted credits ready for blog posting
4. Click "**Copy to Clipboard**" to copy the exported credits
5. Paste into your blog platform!

## 💾 Data Storage

All data is stored locally in your browser using localStorage. Your data persists across sessions but is specific to the browser you're using. To backup your data, export your credits before clearing browser data.

## 🎨 Customization

Feel free to modify the `styles.css` file to match your blog's aesthetic. The color scheme uses CSS variables defined in the `:root` selector for easy customization.

## 🌐 Browser Support

Works in all modern browsers that support:
- HTML5
- CSS3
- JavaScript ES6
- localStorage API
